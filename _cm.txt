Fix Dropbear logging on Rocky Linux 9 (syslog -> /var/log/secure)

Dropbear ran with -E (log to stderr/journald only), so logins never reached
/var/log/secure. On Rocky 9 minimal there is also no rsyslog by default, so
the only way to read logs was 'journalctl -t dropbear', and the IP-limit /
login-checker scripts and the ssh-ws auth-log monitor (which read
/var/log/secure) got no data.

- install.sh: install + enable rsyslog and add authpriv.* -> /var/log/secure
  (00-autoscript-secure.conf) before component install.
- dropbear.service: drop -E so Dropbear logs via syslog (authpriv); keep -F
  for systemd Type=simple; order After=rsyslog.service.
- uninstall.sh: remove the custom rsyslog drop-in.
